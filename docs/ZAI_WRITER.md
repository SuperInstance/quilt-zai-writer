# ZAI Writer Doctrine

ZAI GLM-4.5 is the substrate walker canon's creative voice. It
generates long-form essays anchored to substrate walker doctrines.

## The doctrine

The substrate walker canon doesn't write itself — but it does
*enable* writers. ZAI is one such writer. DeepInfra is another.
DeepSeek is another. Each brings a different voice.

The canon gate is a chord. The writer is one voice in that chord.

## Why ZAI specifically?

ZAI GLM-4.5 has the best balance of:
- Long-form generation (200-400 word essays)
- Doctrine anchoring (it understands abstract substrate)
- Voice distinctiveness (declarative, deriving)
